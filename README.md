# ALU Back-End

This repository contains back-end programming projects completed as part of the African Leadership University curriculum.

## API

### 0. Gather data from an API

The `api/0-gather_data_from_an_API.py` script retrieves an employee's TODO list from a REST API and displays the employee's name, completed task count, total task count, and titles of completed tasks.

Usage:

    ./api/0-gather_data_from_an_API.py EMPLOYEE_ID

Example:

    python3 api/0-gather_data_from_an_API.py 2

## Requirements

- Python 3
- Access to the JSONPlaceholder REST API
